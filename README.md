# YOLOE × Any6D — Open Vocabulary 6D Pose Estimation

> Model-free 6D pose estimation using open-vocabulary detection.  
> Built on [Any6D (CVPR 2025)](https://github.com/taeyeopl/Any6D) + [YOLOE](https://github.com/THU-MIG/yoloe).

---

## Overview

This pipeline combines two state-of-the-art models:

| Model | Role | Output |
|-------|------|--------|
| **YOLOE** | Open-vocabulary detection | Bounding box + segmentation mask |
| **MiDaS** | Monocular depth estimation | Depth map (meters) |
| **Any6D** | 6D pose estimation | 4×4 pose matrix (R \| t) |

**Pipeline:**
```
anchor.jpg + scene.jpg
      ↓
   YOLOE (visual / text / free prompt)
      ↓
   mask + bbox
      ↓
   MiDaS (depth from RGB)
      ↓
   Any6D → 4×4 Pose matrix
      ↓
   3D bounding box on image
```

## Quick Start

### Step 1 — Create GCP VM (Git Bash on Windows)

```bash
# Edit your username
nano create_vm.sh  # change AIMSUSERNAME

bash create_vm.sh
```

### Step 2 — Connect VS Code (PowerShell Admin on Windows)

```powershell
.\setup_windows.ps1

# Then in VS Code:
# Ctrl+Shift+P → Remote-SSH: Connect to Host → select your VM
```

### Step 3 — Setup VM (terminal in VS Code connected to VM)

```bash
bash setup_vm_linux.sh
```

### Step 4 — Run the pipeline

```bash
# In VS Code on the VM:
source master_env/bin/activate

# Open notebook:
# notebooks/YOLOE_Any6D_Pipeline_Final.ipynb
# Select kernel: master_env (Python 3.10)
# Run All ✅
```

## Troubleshooting

| Error | Fix |
|-------|-----|
| `pkg_resources not found` | `pip install setuptools==69.5.1` before requirements.txt |
| `No module named torch` (build) | Add `--no-build-isolation` to pip install |
| `CUDA error: 98` | Wrong `TORCH_CUDA_ARCH_LIST` — set to `8.9` for L4 |
| `no space left on device` | `docker system prune -af` + add `.dockerignore` |
| `Bad owner permissions ssh/config` | Run `icacls` commands in PowerShell Admin |
| `libGL.so.1 not found` | `sudo apt-get install -y libgl1-mesa-glx` |
| `mycpp is None` | Compile mycpp and fix `sys.path` in `Utils.py` |
| `CUDA out of memory` | Resize images to 640×480 before Any6D |
