Fixing SSH Permissions (The `icacls` Solution)

Windows often creates "Bad owner or permissions" errors for `ssh/config`. Run this in PowerShell as Admin:

# Secure your SSH config on Windows
$path = "C:\Users\$env:USERNAME\.ssh\config"
icacls $path /inheritance:r
icacls $path /grant:r "$($env:USERDOMAIN)\$($env:USERNAME):F"
