Claude AI Tips

Master the art of prompting and utilize Claude's advanced project features. These tips cover everything from core frameworks to custom skill building.

ICC Prompting Framework

The ICC Framework is the foundation for high-quality responses:

  • Instruction: Clear, specific action command.
  • Context: Background info, persona, and constraints.
  • Constraint: Limitations (length, format, tone).
Common Mistake: Avoid over-stuffing custom instructions with generic "be concise" rules that conflict with complex tasks.
Projects, Skills & Artifacts

Use Projects to maintain context over long conversations and Skills for repeatable workflows.

  • Artifacts: Claude can generate HTML/JS dashboards, flowcharts (Mermaid), and interactive trackers.
  • Dashboards: "Match the colors of this logo for the dashboard".
  • Flowcharts: "Create a flowchart showing an in-depth customer onboarding process".
Connectors & Integration

Link Claude directly to your workspace tools:

  • Google Drive: Analyze docs in real-time.
  • Slack: Summarize threads or draft replies.
  • Notion: Sync notes and project updates.

GCP on VS Code via VM

Setup a high-performance GPU instance on GCP and connect your local VS Code environment seamlessly using IAP tunneling.

Step 1: Create the VM

Run this script in Git Bash or WSL on Windows. It creates a VPC, firewall, NAT, and the L4 GPU instance.

# Create VM instance with L4 GPU
gcloud compute instances create ${VM_NAME} \
    --zone=${ZONE} \
    --machine-type=g2-standard-4 \
    --accelerator="type=nvidia-l4,count=1" \
    --image-family=common-cu129-ubuntu-2204-nvidia-580 \
    --image-project=deeplearning-platform-release \
    --maintenance-policy=TERMINATE \
    --network=${AIMSUSERNAME}-vpc \
    --scopes=storage-full,cloud-platform
Download create_vm_1.sh
Step 2: Windows SSH Setup (Admin)

Run this in PowerShell as Administrator to fix permissions and generate the SSH config.

Error: "Bad owner or permissions on ssh/config". Fix: Use icacls to restrict permissions to only your user. 
# Fix .ssh folder permissions
icacls "C:\Users\$env:USERNAME\.ssh" /inheritance:r
icacls "C:\Users\$env:USERNAME\.ssh" /grant:r "$env:USERDOMAIN\$env:USERNAME:F"

# Generate config
gcloud compute config-ssh --project=$PROJECT_ID
Download setup_windows.ps1
Step 3: Linux VM Setup

Once connected to the VM via VS Code, install Docker and the NVIDIA Container Toolkit.

# Install Docker + Toolkit
sudo apt-get install -y docker.io docker-compose-v2
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
Verified: `docker run --rm --gpus all nvidia/cuda:12.1.1-base-ubuntu22.04 nvidia-smi` confirms GPU access.

YOLOE + Any6D Install

Deploy the open-vocabulary 6D pose estimation pipeline. Combines YOLOE detection, MiDaS depth, and Any6D pose estimation.

The Pipeline Logic

The workflow flows from 2D detection to 3D pose:

  1. YOLOE: Visual/Text/Free prompt to get mask + bbox.
  2. MiDaS: Estimate depth from RGB scene.
  3. Any6D: Generate 4x4 Pose matrix (R | t).
Detection Modes (Python) 
# Visual prompt (anchor image)
bbox, mask, conf, _ = yoloe_visual_prompt(model, SCENE_PATH, ANCHOR_PATH)

# Text prompt
bbox, mask, conf, _ = yoloe_text_prompt(model, SCENE_PATH, ['tennis ball'])
GPU & Architecture Config

Crucial environment variables for model compilation:

# For NVIDIA L4 (GCP G2 Instances)
export TORCH_CUDA_ARCH_LIST="8.9"
Error: `CUDA error: 98` usually means wrong ARCH list. Ensure it matches your GPU compute capability.
Troubleshooting & Fixes
  • pkg_resources: `pip install setuptools==69.5.1`
  • libGL error: `sudo apt-get install -y libgl1-mesa-glx`
  • Out of Memory: Resize images to 640x480 before Any6D.
  • No space: `docker system prune -af`
