# Project Overview: Prompt Guide

This directory is a collection of resources, guides, and notes focused on AI prompting techniques and features. It serves as a knowledge base for effectively using AI models, particularly Claude AI, through structured frameworks and advanced platform tools.

## Key Files

- **claude.md**: A detailed breakdown of Claude AI's capabilities. It covers:
    - Prompting fundamentals and the ICC framework.
    - Platform features: Web search, file uploads, and model selection.
    - Advanced tools: Artifacts (HTML/CSS/JS visualizations, dashboards), Deep Research, and Projects.
    - System-building: Custom instructions, knowledge bases, and Skills for repeatable workflows.
    - Integrations: Connectors for Google Drive, Slack, Asana, and Notion.

## Usage

The contents of this directory are designed for:
1. **Reference**: Quickly looking up specific prompting techniques or AI feature capabilities.
2. **Learning**: Following structured "chapters" or notes to master AI toolsets.
3. **Template/Framework Application**: Using concepts like the ICC framework or Artifact patterns in new AI interactions.

## Development Conventions

- **Formatting**: Documentation should be maintained in Markdown format for readability and structure.
- **Organization**: New guides should follow a clear header structure (e.g., Overview, Chapters, Links) as seen in existing files.
